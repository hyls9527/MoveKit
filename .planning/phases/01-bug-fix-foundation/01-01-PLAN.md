   ```go
   newPtr, _ := syscall.UTF16PtrFromString(newPath)
   ```
   Change to log errors via the migrate.Logger. Since shell.go is in package `winsyscall` and migrate.Logger is in package `migrate`, we face a circular dependency risk. Use a simpler approach:
   - Import `"fmt"` and `"os"` (already available in stdlib)
   - Write a package-level fallback: if UTF16PtrFromString fails, write to stderr via `fmt.Fprintf(os.Stderr, ...)` as a last-resort log, then return without calling SHChangeNotify

   Implementation:
   ```go
   func NotifyFolderRenamed(oldPath, newPath string) {
       oldPtr, err := syscall.UTF16PtrFromString(oldPath)
       if err != nil {
           fmt.Fprintf(os.Stderr, "winsyscall: NotifyFolderRenamed utf16 oldPath %q: %v\n", oldPath, err)
           return
       }
       newPtr, err := syscall.UTF16PtrFromString(newPath)
       if err != nil {
           fmt.Fprintf(os.Stderr, "winsyscall: NotifyFolderRenamed utf16 newPath %q: %v\n", newPath, err)
           return
       }
       SHChangeNotify(SHCNE_RENAMEFOLDER, SHCNF_PATH,
           uintptr(unsafe.Pointer(oldPtr)),
           uintptr(unsafe.Pointer(newPtr)))
   }
   ```
