<objective>
Refactor the migrate package to route all syscall calls through the SyscallLayer interfaces (created in Plan 03-01) instead of calling package-level syscall functions directly. This enables mock injection in tests, which is the prerequisite for all Phase 3 migrate test coverage work (Plans 03-03 and 03-04).

Purpose: Without this wiring change, migrate tests cannot inject mock syscall implementations and would be forced to call real Win32 APIs, violating D-07 and D-08. The refactoring is purely mechanical — no functional behavior changes.

Output: `internal/migrate/syscall_bridge.go` (package-level Sys variable), updated `internal/migrate/*.go` files (call sites refactored), updated existing test files (mock initialization).
</objective>
